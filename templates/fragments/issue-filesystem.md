Fills `{{ISSUE_WORKFLOW}}` when project tracks issues as local files, no external tracker. Copy body below (under the rule) into AGENTS.workflow.md's `### Tracking issue` section.

---

- No external tracker — the "issue" is a tracked file, `.claude/issues/<slug>.md`; `issue` on the parent card is that path. Candidates: `grep -L '^Closed:' .claude/issues/*.md` filtered by goal keywords (an exact title: `grep -l '^# <title>$'`), filenames only — the orchestrator never reads a body; `spec-author` reads each with `sh .claude/scripts/extract-section.sh '## Goal' <file>`. Reuse + reference its filename; never create a second. Open titles (gate 4, for `spec-author`'s follow-up dedupe): `grep -L '^Closed:' .claude/issues/*.md | xargs -r sed -n '1s/^# //p'`.
- File, never retyped: `cp .claude/tasks/artifacts/<slug>/issue-body.md .claude/issues/<slug>.md` — line 1 is `# <title>`, the rest the body. Reuse: `issue-request.sh` does not read files — copy the old file's body into `artifacts/<slug>/request.md` yourself before the first rewrite. Commit it with the branch's squash, not on `main`.
- Status line (gate 2 approval, a split filed, CI green — never a body rewrite): `tail -n +2 .claude/issues/<slug>.md > .claude/tasks/artifacts/<slug>/issue-live.md`, `sh .claude/scripts/issue-body.sh <slug> --status .claude/tasks/artifacts/<slug>/issue-live.md > .claude/tasks/artifacts/<slug>/issue-status.md`, then write the title line back above it: `{ head -1 .claude/issues/<slug>.md; cat .claude/tasks/artifacts/<slug>/issue-status.md; } > .claude/tasks/artifacts/<slug>/issue-file.md && mv .claude/tasks/artifacts/<slug>/issue-file.md .claude/issues/<slug>.md`. Comment (a kept spec change): append `.claude/tasks/artifacts/<slug>/issue-comment.md` under a `## Changelog` heading at the end of the file (the body above is the spec as filed, the changelog below its history). Follow-up (gate 4): `cp .claude/tasks/artifacts/<slug>/follow-up-<k>.md .claude/issues/<its slug>.md` after `Found in <issue path>` is appended to it.
- Close: the human prepends `Closed: <PR URL>` as the file's first line after the merge — keeps it out of the reuse search above without deleting history. `pr-body.sh` appends no closing line for a path.
