Fills `{{ISSUE_WORKFLOW}}` when project tracks issues in Jira via REST API credentials. Copy body below (under the rule) into AGENTS.workflow.md's `### Tracking issue` section.

---

- Credentials in `.claude/jira.local.json` (gitignored, never committed, never logged, never quoted in output): `baseUrl`, `email`, `apiToken`. Missing/unreadable → stop, ask the user to run through the bootstrap's Jira setup again.
- Candidates: search Jira (REST `/rest/api/3/search`, JQL on `summary ~ "<goal keywords>"`; an exact title: `summary ~ "\"<title>\""`) for an open issue with the same goal, keys only; `spec-author` reads any candidate with `bash .claude/scripts/issue-view.sh <key>`, never a raw REST fetch dumped into context. Reuse + reference its key; never open a second. Open titles (gate 4, for `spec-author`'s follow-up dedupe): the same search with `statusCategory != Done`, `summary` field only.
- File via REST `/rest/api/3/issue`: `summary` = line 1 of `.claude/tasks/artifacts/<slug>/issue-body.md` with its `# ` stripped, `description` = the rest, both read from the file into the JSON payload (`jq -Rs`), never retyped. Reuse: `PUT /rest/api/3/issue/<key>` with the same fields.
- Status line (gate 2 approval, a split filed, CI green — never a body rewrite): `GET /rest/api/3/issue/<key>?fields=description`, the description text into `.claude/tasks/artifacts/<slug>/issue-live.md`, `sh .claude/scripts/issue-body.sh <slug> --status .claude/tasks/artifacts/<slug>/issue-live.md > .claude/tasks/artifacts/<slug>/issue-status.md`, `PUT /rest/api/3/issue/<key>` with that file as `description` (`jq -Rs`). Comment (a kept spec change): `POST /rest/api/3/issue/<key>/comment` with `.claude/tasks/artifacts/<slug>/issue-comment.md`'s content the same way. Follow-up (gate 4): create from `follow-up-<k>.md` exactly as the file command above, after `Found in <key>` is appended to it.
- Close: the human transitions the issue to its done state after the merge (`POST /rest/api/3/issue/<key>/transitions`, or in Jira); the PR body's `references <key>` line (appended by `pr-body.sh`) links it but closes nothing.
